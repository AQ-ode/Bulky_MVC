# Bulky Book

Bulky Book is an e-commerce platform for selling books, built with .NET 8, Entity Framework Core, and Stripe for payment processing.

## Features 
- User authentication and authorization
- Book catalog and categories
- Shopping cart and order processing
- Admin panel for managing books and orders
- Stripe payment integration

## Technologies
- .NET 8
- Entity Framework Core
- ASP.NET Core MVC
- Stripe API
- SQL Server
- HTML, CSS, JavaScript

## Installation
1. Clone the repository
    ```bash
    git clone https://github.com/AQ-ode/Bulky_MVC.git
    cd Bulky_MVC
    ```
2. Configure `appsettings.json` for your database and Stripe keys.
3. Apply migrations and run the application
    ```bash
    dotnet ef database update
    dotnet run
    ```
